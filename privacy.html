Privacy Policy — Aphelion uploader

Last updated 22 November 2026.

What this application is

"Aphelion uploader" is a private tool used only by the owner of the Aphelion YouTube channel to upload the channel's own videos, set their titles, descriptions, thumbnails and captions, and read the channel's own YouTube Analytics. It is not offered to, installed by, or used by anyone else.

Google user data

Through the YouTube Data API and YouTube Analytics API the application accesses only the Aphelion channel's own videos, playlists and analytics, with the channel owner's consent. That data is used solely to publish and review the channel's own content. It is not shared with, transferred to, or sold to any third party, and it is not used for advertising.

The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage

The owner's OAuth credentials and the analytics reports are stored locally on the owner's own computer. No server, database or third-party service holds them. No cookies are set by this website.

Visitors to this website

This website collects no personal information and uses no analytics or tracking.
